# AIK 产品与工程配置

## 1. 产品定位

AIK 是 RAG 知识库项目的产品名称，本 App 是该项目的原生 iOS 访问端。一个系统账号可能属于多个 SaaS 租户，因此“登录系统账号”和“选择企业知识空间”是两个独立步骤。用户未明确选择租户前，不能进入聊天或向任何知识空间发送问题。非 iOS 的产品、服务端、商务和客户资料统一维护在 [AIK / RAG 知识库项目文档中心](../../../../documents/RAG/README.md)。

首版目标是安全复用现有 `H5/AIChat` 的核心访问能力：

- SaaS 系统账号登录；
- 按服务端授权结果搜索、选择和切换租户；
- 邀请链接、激活码及允许匿名访问的租户；
- 最近会话、历史消息、SSE 流式问答、评价与清空历史；
- 租户启用语音时录音、识别并继续流式问答；
- 中英文、iPhone、辅助功能及深色模式。

## 4. API 环境

Debug 和 Release 都固定使用：

```text
https://app.jaronsoft.com/api
```

接口路径在 `APIClient` 中与基础地址拼接。应用不提供环境输入框，不向包内写入 API Key，不降低 HTTPS 要求。本项目只消费线上接口，不修改 `API/`、数据库、服务器配置或线上部署。

## 5. 资源与系统能力

- App Icon 由 `H5/AIChat/public/favicon.png` 生成 1024×1024 RGB 图标。
- 启动背景及基础 UI 使用 AIK 蓝色知识空间风格。
- 自定义 URL Scheme 为 `aik://`。
- 麦克风只在用户触发语音提问时申请。
- `PrivacyInfo.xcprivacy` 声明 `UserDefaults` required-reason API，以及账号标识、问题内容和按需语音数据的应用功能用途。
- 当前线上没有 AASA 文件，因此不声明 Associated Domains，也不承诺 HTTPS Universal Link 自动唤起。

## 6. 功能边界

首版不包含：

- 知识库后台管理、文档上传或租户配置修改；
- 注册、找回密码、Apple 登录；
- 付费、订阅、IAP；
- Push Notifications；
- 绕过服务端租户授权的本地入口。

## 7. 可访问性与适配

界面使用 SwiftUI 语义组件和可伸缩系统字体，支持 Dynamic Type、VoiceOver、深色模式、Reduce Motion、键盘交互式收起及 iPhone 自适应。Logo 等纯装饰元素隐藏于辅助功能树；录音和发送按钮提供明确的可访问性标签。
