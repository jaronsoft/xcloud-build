# AIK 接口与登录租户流程

## 1. 总体流程

```text
启动
  → 从 Keychain 恢复系统/访客会话
  → 未登录：输入 6 位空间访问码、扫码/点击访问链接，或系统账号登录
  → 访问码：POST KnowledgeAccess/ResolveSpace
  → 系统登录成功：GET KnowledgeAccess/MyTenants
  → 用户明确选择企业知识空间
  → 匿名空间继续完成图形验证码，或按原邀请码流程进入
  → 加载最近会话和历史消息
  → StreamAsk 流式问答
```

“切换企业”仅清除当前租户选择并返回租户列表，保留系统登录；“退出账号”清除身份、token、已选租户和当前用户关联缓存。

## 2. 系统账号登录

生产基础地址为 `https://app.jaronsoft.com/api`。密码不明文提交：

1. `GET /crypto/nonce` 获取 `NonceId` 与 nonce。
2. `GET /crypto/publickey` 获取服务端 RSA 公钥参数。
3. 客户端使用与现有 Web 端一致的 AES-CBC 生成加密密码，再使用 RSA PKCS#1 加密 AES 密文。
4. `POST /auth/v2/login`，提交 `LoginId`、`EncryptedPassword`、`NonceId`、设备说明和保持登录选项。
5. 成功后保存 JWT、refresh token 和最小用户摘要到 Keychain；不保存密码。

连续登录失败达到安全阈值，或服务端返回“验证码不能为空/Captcha required”时，客户端自动调用 `/auth/snowflake` 和 `/auth/generate-captcha` 展示图形验证码。后续登录请求同时提交 `Captcha` 与 `CaptchaKey`；验证失败会清空密码和验证码并刷新图片，避免重复使用已消费的验证码。

系统登录失败不会进入租户列表。401/403 统一显示登录状态失效提示，不使用本地缓存绕过授权。

## 3. 租户列表与选择

系统登录后调用：

```http
GET /api/KnowledgeAccess/MyTenants
Authorization: Bearer <JWT>
x-lang: zh-CN
```

仅展示该账号获授权且当前可用的企业空间，不调用公开空间目录。用户选择后以接口返回的空间摘要建立当前知识空间上下文。所有 ID 以字符串保存；只在旧接口确实要求整数参数且能安全转换时才临时转为 `Int64`。

选定后的业务请求统一携带：

```http
Authorization: Bearer <JWT>
X-Knowledge-Tenant-Id: <tenant-id>
x-tenantid: <tenant-id>
x-lang: zh-CN
```

邀请访问另按接口约定携带 `x-code`。当前租户与最多 6 个最近租户摘要存入 `UserDefaults`，token 不进入 `UserDefaults`。

## 4. 邀请、匿名访问与链接

未登录入口不展示企业空间总目录，只提供 6 位数字空间访问码、扫码/链接和系统账号登录。访问码固定为 6 位且全局唯一，可接受纯数字、空格或连字符输入；它只用于定位空间，不是访问授权。

空间访问码调用：

```http
POST /api/KnowledgeAccess/ResolveSpace
Content-Type: application/json

{"AccessCode":"123456"}
```

只有同时处于激活状态并开启 `AllowAnonymous` 的空间才能解析成功。未开启匿名访问、空间停用、访问码错误或已重置时统一返回“访问码无效或空间不可用”，不得泄露租户 ID 或详细状态。解析成功后仍必须通过图形验证码，再由 `/KnowledgeAccess/Session` 创建限定租户的访客会话。

入口同时兼容：

- `https://ai.jaronsoft.com/s/<6位访问码>`；
- H5 邀请链接；
- 激活码；
- 租户 ID；
- `aik://tenant/<tenantId>/<code>`；
- 带 `tenantId`/`tid` 与 `code`/`ic` 查询参数的链接。

激活码调用 `GET /KnowledgeMember/GetCodeStatus`。链接携带有效邀请码时优先进入原邀请码流程。访问码解析成功仅确认空间摘要；匿名访问仍通过 `/auth/snowflake`、`/auth/generate-captcha` 和 `/KnowledgeAccess/Session` 建立限定租户的会话。

`PublicTenants` 仅保留给兼容客户端，并且只返回后台明确开启“公开目录展示”、允许匿名访问且处于激活状态的演示空间。AIK iOS、Android 与 H5 首屏不调用或展示该目录。系统账号只展示 `MyTenants` 返回的授权空间。

截至 2026-07-27，线上未部署 AASA 文件，故 HTTPS 链接只能在 App 内粘贴解析，或由用户通过分享/复制进入；不承诺 Universal Link 自动打开 App。自定义 `aik://` 链接可唤起已安装的应用。

## 5. 会话与聊天接口

原生端使用安装级随机 fingerprint 恢复会话：

- `GET /KnowledgeChat/GetLatestSessionByFingerprint`
- `GET /KnowledgeChat/GetSessionMessages`
- `POST /KnowledgeChat/StreamAsk`
- `POST /KnowledgeChat/ClearHistory`
- `POST /KnowledgeChat/SubmitRating`
- `POST /KnowledgeChat/VoiceAsk`

`StreamAsk` 使用 `text/event-stream`。解析器支持 TCP 分包和多包粘连，并识别：

| 数据 | 行为 |
| --- | --- |
| 普通 `data:` | 追加 Markdown 内容 |
| `__STATUS__` | 更新“检索中/思考中”等状态 |
| `__ERROR__` / `[API_ERROR]` | 结束流并展示服务错误 |
| `__METADATA__` | 更新消息 ID、会话 ID 与日志时间 |
| `[DONE]` | 正常结束 |

连接中断且已有部分内容时保留内容并追加中断提示；完全空回复显示服务不可用。服务端返回的无权限、会员到期等业务消息直接呈现，不在客户端改写授权。

Markdown 使用系统 `AttributedString` 呈现文本、强调、链接和代码；图片链接单独解析并通过 `AsyncImage` 加载。消息支持复制、赞同、不准确和改进建议。

## 6. 语音

只有 `EnableVoice == true` 的租户显示语音按钮。用户点击后才申请麦克风权限，使用 `AVAudioRecorder` 录制单声道 AAC/M4A 并上传 `VoiceAsk`。接口返回识别文本后，将文本作为普通问题进入 `StreamAsk`；密码和 token 不参与音频元数据。

## 7. 本地数据与清理

| 数据 | 位置 | 清理时机 |
| --- | --- | --- |
| JWT、refresh token | Keychain | 退出账号、建立新访客会话 |
| 用户最小摘要、邀请凭据 | Keychain | 退出账号 |
| 当前/最近租户 | `UserDefaults` | 当前租户在切换时清除；全部在退出时清理当前选择 |
| 安装 fingerprint | `UserDefaults` | 保留以恢复该安装的会话 |
| 密码、录音临时文件 | 不持久化/临时目录 | 请求后或失败后清理 |

线上接口暂时不会调整，客户端按当前数据契约实现兼容解码；任何未来接口变更都应先增加兼容测试，再发布客户端。
