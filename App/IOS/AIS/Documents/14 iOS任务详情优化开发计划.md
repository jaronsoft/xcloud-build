# iOS 任务详情优化开发计划

> 状态：✅ 开发完成并上传 TestFlight，待真机与 Device Hub 交互回归
>
> 完成日期：`2026-07-26`

## 1. 开发目标

本轮优化 AIS iOS 任务详情页、成果图片预览和任务列表卡片，重点解决预览关闭、操作按钮布局、分享文案、任务编号和成果信息展示问题。

本轮已完成代码实现、专项自动化验证、Release Archive 和 TestFlight 上传。

## 2. 开发范围

### 2.1 成果图片预览

- 修复全屏成果预览左上角关闭按钮不可点击的问题。
- 调整关闭控件的视图层级、点击区域和手势优先级；按钮视觉尺寸保持 `44 × 44 pt`，实际触控区域扩大至 `60 × 60 pt`，并适配安全区。
- 保存、导出或分享完成后不自动关闭预览，由用户通过关闭按钮主动退出。
- 单击图片显隐控制区，双击在原始比例与 `2x` 之间切换，双指支持 `1x` 至 `5x` 缩放，放大后可单指拖动。
- 原始比例下支持向下滑动关闭；实际位移达到 `100 pt` 或预测位移达到 `180 pt` 时退出，未达阈值自动回弹。
- 左右滑动继续切换成果，不增加左滑关闭，避免与分页手势冲突。
- 下滑过程中图片跟手位移、背景和控制区同步淡出；视频预览保持原交互，避免与播放控件冲突。

### 2.2 任务详情操作区

- 四个操作按钮调整为两行等宽布局：
  - 第一行：保存到相册、导出到文件。
  - 第二行：分享案例、继续修改。
- 统一按钮高度、圆角、图标尺寸、间距和加载状态。
- 保存到相册保持主操作样式，导出到文件使用次级样式。
- 分享案例使用明确的品牌强调色，避免呈现为不可用的灰色按钮。
- 继续修改保持次级操作层级。

### 2.3 文案调整

- 中文“导出到 Files”改为“导出到文件”。
- iOS 任务列表、任务详情、成果预览和案例相关入口的“分享作品”统一改为“分享案例”。
- 英文文案同步采用自然、统一的本地化表达。

### 2.4 任务信息

- 任务详情增加任务创建时间。
- 任务详情显示完整任务编号，不再仅显示后 8 位。
- 任务列表卡片显示完整任务编号，不再仅显示后 6 位。
- 任务编号继续使用 `String` 建模和展示，避免雪花 ID 精度丢失。
- 完整任务编号使用适合长数字的布局，必要时支持选择复制。

### 2.5 成果规格

任务详情在数据存在时显示以下信息：

- 画面比例，例如 `16:9`。
- 清晰度目标，例如 `1536`。
- 文件大小，例如 `2.44 MB`。
- 生成耗时，例如 `1 分 55 秒`。

成果规格使用可选字段，历史任务缺少对应数据时隐藏该项，不显示无意义占位。iPhone 使用紧凑双列布局，iPad 和宽屏环境根据可用宽度适配。

### 2.6 数据契约

- 扩展任务详情 API 的可选响应字段，提供画面比例、清晰度目标、文件大小、像素尺寸和生成耗时。
- 优先从结构化任务输入、输出和最终成果资产中读取数据，避免 iOS 依赖不稳定的多形态 JSON。
- 编辑链任务的数据应对应当前实际展示的最终成果。
- 不修改数据库结构，不执行存量数据迁移。
- 历史接口响应和缺失字段必须保持兼容。

### 2.7 分享流程

- 统一任务列表、任务详情和成果预览的分享案例流程。
- 生成分享内容前调用现有公开分享接口，确保分享链接已获得公开访问授权。
- 分享处理中阻止重复请求，并提供明确的加载和错误状态。

## 4. 验收标准

- 全屏预览左上角关闭按钮在未缩放、缩放和拖动图片后均可正常退出。
- 全屏图片预览可单击显隐控件、双击缩放、双指缩放，并在原始比例下通过垂直向下手势关闭。
- 水平滑动仍用于成果分页，放大后的图片拖动不会误触发关闭。
- 四个操作按钮在 iPhone 上保持两行等宽布局，无截断、重叠或异常灰色状态。
- 中文界面不再出现“导出到 Files”和“分享作品”。
- 任务详情和任务列表均能显示完整雪花任务编号。
- 任务详情能够显示任务创建时间。
- 成果规格有值时格式正确，无值时布局自动收拢。
- 任务详情、成果预览和任务列表的分享案例行为一致，公开链接可正常访问。
- 页面兼容 iPhone、iPad、深色模式、Dynamic Type 和 VoiceOver。

## 5. 默认约定

- 不修改数据库结构。
- 历史任务缺少成果元数据时隐藏对应信息。
- 保存、导出或分享完成后不自动关闭图片预览。
- 本轮不调整删除任务、继续修改、相册权限和系统分享面板的既有业务规则。
- 本轮不包含 App Store 审核与正式发布操作。
