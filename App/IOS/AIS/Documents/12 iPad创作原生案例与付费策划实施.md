# iPad 创作、原生案例与付费策划实施

## 1. 实施范围

本轮构建为 `1.0 (20260725.5)`，修改范围包括 `App/IOS/AIS/` 与 API 属性会员权限判断，不新增接口和数据库结构。

目标是消除 iPad 横屏内容区域过窄的问题，统一原生案例入口与宣传标识偏好，并把 AI 识图、AI 策划和最终生成纳入明确的报价确认链路。

## 2. iPad 与案例布局

- 页面根据实际容器宽度而不是设备尺寸类别决定布局，兼容横屏、竖屏和分屏。
- 页面内容最大宽度为 1200pt；iPad 保留 28pt 水平安全边距。
- 模板案例使用手机两列、iPad 竖屏三列、横屏四列。
- 生图案例使用手机一列、iPad 竖屏两列、横屏三列。
- 产品智造和模板制作在可用宽度达到 900pt 时使用双列，否则回退为单列。
- 首页移除重复任务快捷入口，统一为“模板案例”和“生图案例”；两者均为原生页面，不打开 `/public-showcase`。

## 3. 设置、模型与属性

- `ais.promo_mark_enabled` 是宣传标识的唯一默认值，产品智造、模板制作与系统设置实时共享。
- 新草稿不保存宣传标识快照；旧草稿中的历史字段可兼容解码，但不会覆盖当前全局偏好。
- 模型区域默认只展示当前模型、推荐状态、倍率和摘要；可选模型在独立选择页展示完整说明与锁定原因。
- 模型选择同时遵循接口 `CanUse` 和 `CanSelect`；模板固定模型不打开无效选择页。
- 视觉方向、视觉效果和社媒模板直接展示；镜头、版式、构图、用途、卖点表达、质量约束和参考图使用方式按组折叠。
- API 属性会员等级补充 `enterprise`，属性缓存版本由 `v11` 升级至 `v12`，避免沿用错误权限缓存。

## 4. 识图、策划与生成确认

- 从相册、剪贴板或素材库加入单张图片后主动打开素材设置；多图上传提示用户逐张补充。
- 素材卡片展示 AI 识图入口和识别中、已补全、失败状态。
- AI 识图先使用 `generationType=image_understand` 请求 `/api/ais/billing/quote`；确认后才上传本地图片并创建任务。
- AI 策划先使用 `generationType=prompt_optimize` 报价；素材已有识图说明时，即使文字输入为空也允许策划。
- 识图结果回填素材说明，用户仍可编辑；失败不覆盖原内容并支持重试。
- 未启用有效优化提示词时，生成前提示先策划、仍然生成或取消；继续后仍展示现有最终点数确认。
