# 产品智造配置与全屏图片浏览实施

## 1. 实施范围

本轮统一 AIS Web、API 与 iOS 的产品智造配置，并在 iOS 建立共享全屏图片浏览能力。数据库结构和公开 API 响应结构保持不变。

本轮能力最初随 `1.2.2 (260726.5)` 上传 App Store Connect，现由包含任务详情优化的 `1.2.3 (260726.6)` 继续承接 TestFlight 回归。

## 2. 产品智造配置

- `direction`、`effect` 和 `social_template` 不再重复出现在 iOS 扩展属性列表。
- 视觉效果最大选择数统一读取后台 `effect.MaxSelected`，缺失或非法时回退为 `3`；AIS Web 和 iOS 的草稿恢复、任务复用与继续编辑都会裁剪超额选择。
- iOS 输出规格按可用宽度排列：方向 3 列、比例 4 列、清晰度 3 列；极窄宽度和无障碍大字号自动降为 2 列或 1 列。
- 会员受限规格继续展示但不可选择，中文徽标统一为“VIP 可用”“Pro 可用”“企业可用”。
- 生成模型倍率统一展示为“点数 ×1”“点数 ×1.3”，英文为 `Points ×1`，不保留无意义尾零。
- 产品智造顶部改为紧凑信息条，保留当前视觉方向和简短引导，减少重复标题及介绍占用。
- `GET /api/ais/prompt-attributes` 按请求语言读取后台会员配置名称，公共缓存键加入语言维度，避免中英文标签互相污染。

## 3. iOS 全屏图片浏览

- 案例主图与按 `Index` 排序的有效用户参考图组成同一浏览集合；点击任意参考图会从对应位置打开。
- 模板详情顶部主图支持单图全屏浏览；同模板案例继续进入 `GalleryDetailView`，只浏览当前案例及其参考图。
- 全屏图片支持 `1x–5x` 双指缩放、`1x/2x` 双击切换、放大后拖动和原始比例左右分页。
- 缩放层只在画面放大后接管单指拖动；原始比例下不再挂载全屏拖动手势，避免与外层 `TabView` 分页竞争而导致多图无法左右切换。
- 切换图片时重置缩放及位移；放大状态下分页手势暂停，拖动优先作用于当前图片。
- 多图显示可横向滚动的底部缩略图、选中描边和当前位置；单图隐藏缩略图栏。
- 长按当前图片显示原生“保存到相册”菜单，用户确认后才申请 `.addOnly` 权限。
- 保存使用原始 URL 数据，不使用列表或详情缩略图；保存成功、权限拒绝和下载失败均提供中英文提示，并阻止重复保存。
- 任务成果页复用同一缩放组件，同时保留原有保存、分享按钮和鉴权下载行为。

## 4. 验证

- API `AisPromptAttributeStoreTests`：`11/11` 通过。
- AIS Web 生产构建与 Bundle 体积门禁通过；构建仅保留 `@microsoft/signalr` 依赖中的既有 Rolldown 注解警告。
- iPhone 17 Pro、iOS 26.5 模拟器完整 `AISTests`：`41/41` 通过。
- 图片浏览专项测试：`4/4` 通过，覆盖参考图排序和过滤、初始选择、集合变化后的选择修正以及缩放和位移边界。
- `2026-07-29` 多图分页修复后重新运行 `AISImageGalleryViewerTests`：`6/6` 通过；原始比例保留分页，放大后继续支持画面拖动。

## 5. TestFlight 回归重点

- 中文和英文下核对会员徽标、模型倍率、紧凑顶部和响应式输出规格。
- 核对视觉效果最多选择后台指定数量，旧草稿不会恢复超额选项。
- 在案例主图、每张参考图、模板主图和同模板案例中验证全屏入口。
- 使用横图、竖图和长图验证分页、缩略图、双指缩放、双击、拖动与切图重置。
- 真机验证首次相册授权、拒绝授权、长按保存和重复点击保护；模拟器测试不能替代真实相册权限回归。
- 使用 VoiceOver、最大无障碍字号、横屏和 iPad 分屏检查安全区域与控件可达性。
