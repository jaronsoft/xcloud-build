# iOS 任务列表、创作选项与缓存诊断优化

> 状态：✅ 代码完成、模拟器测试通过并已上传 TestFlight，待真机回归
>
> 完成日期：`2026-07-26`

## 1. 实施目标

本轮优化任务列表信息密度、产品智造规格卡片和扩展属性选择体验，同时建立可分模块管理、可跨重启导出的图片缓存诊断能力。任务详情和成果全屏预览继续保留“分享案例”，任务列表不再提供分享入口。

## 2. 已完成内容

### 2.1 任务列表与取消错误

- 移除任务列表的分享状态、分享请求和分享按钮。
- 成功任务优先展示用户任务描述，最多两行；描述缺失时回退成功状态文案。
- 运行中任务继续显示进度和预计时间，失败任务继续显示错误摘要。
- 缩略图改为固定方形区域、`scaledToFit` 和中性背景，横图、竖图及长图均完整显示。
- 统一识别 `CancellationError` 和 `URLError.cancelled`，页面退出、参数变化和新请求替换旧请求引发的正常取消不再显示红色错误。
- 报价结果写入前再次检查任务取消状态，避免旧报价覆盖最新规格。

### 2.2 创作规格与选择器

- 规格卡片标题和详情使用稳定行数，普通字号下统一最小高度。
- 会员标签通过右下角 overlay 固定展示，正文为标签预留空间。
- 无障碍大字号下切换单列并允许卡片自然增高。
- 镜头语言、光线、构图等扩展属性统一改为摘要行。
- 点击摘要行复用现有 `CreationPlanningPicker`：iPhone 使用可滚动 sheet，iPad 使用系统自适应表单样式。
- 保留单选、多选、最大选择数和会员权限规则。

### 2.3 图片交付

- `AISImagePreset` 增加 `.original`。
- 任务、模板、案例、项目和素材列表继续使用 capabilities 下发的 CDN 缩略规则。
- 页面内详情图继续使用 `detail=1200px`。
- 全屏缩放预览使用原图 URL，不附加缩略参数。
- 保存到相册和导出文件继续使用原图数据。
- 客户端不硬编码 CDN 域名或处理参数。

### 2.4 缓存管理

- 图片缓存继续按最终 URL 全局去重，并增加任务、案例/模板、项目/素材和其他模块标签。
- 新增解码后 `UIImage` 内存缓存，避免重复从磁盘 Data 解码。
- 保留磁盘缓存、并发请求合并、7 天有效期和磁盘容量控制。
- 新增缓存统计：模块逻辑大小、文件数、总物理占用和最后更新时间。
- 共享图片物理文件只保存一份，允许同时关联多个模块。
- 无法识别归属的历史缓存归入“其他缓存”，保持兼容。
- “我的—存储”新增缓存管理页面，可分别清理任务、案例/模板、项目/素材、其他和接口数据，也可清理全部。

### 2.5 诊断日志

- 图片缓存事件记录模块、preset、内存命中、磁盘命中、请求合并、CDN 下载、字节数、耗时、缓存写入、过期、取消、失败和清理结果。
- URL 日志只保留域名、路径、preset 和不可逆缓存键摘要，不记录查询凭证、Token、用户 ID 或图片内容。
- Debug 与 TestFlight 环境启用持久化滚动日志，保留最近 7 天且最大 2 MB。
- 正式 App Store 环境不启用详细持久化缓存日志。
- 开发诊断页可导出统一脱敏 `.log`，包含版本、系统、缓存事件和 API 请求。
