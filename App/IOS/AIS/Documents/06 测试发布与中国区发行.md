# 测试、发布与中国区发行

<!-- markdownlint-disable MD013 -->

## 1. 发布策略

采用两阶段发行：

1. **海外首发**：WeKare Partners LLC 提交 TestFlight 和 App Store，只选择已经完成支付、隐私、模型和客服准备的国家和地区。
2. **中国大陆发行**：佳融公司完成 APP 备案、业务许可定性、生成式 AI 应用登记、境内部署和专项验收后，再增加 China mainland storefront。

同一代码库通过服务端能力和构建环境控制区域差异，不维护两套业务逻辑。

## 2. 环境矩阵

| 环境 | API/数据 | Apple | 用途 |
| --- | --- | --- | --- |
| Development | 本地或测试数据 | StoreKit Configuration、APNs sandbox | 日常开发 |
| Overseas Staging | 海外测试环境 | Sandbox/TestFlight | 集成和审核预演 |
| Overseas Production | 海外生产 | App Store production | 海外正式发行 |
| China Staging | 境内测试环境 | Sandbox/TestFlight/限定构建 | 中国专项验收 |
| China Production | 境内生产 | China storefront | 备案完成后正式发行 |

测试和生产数据库、Redis、对象存储、APNs token、StoreKit 通知环境必须隔离。

App Store 审核和 TestFlight 使用 Apple Sandbox 交易。若其 API 指向生产服务，只允许明确配置的审核账户处理 Sandbox 签名交易：生产环境设置 `AIS__StoreKit__SandboxAllowedUserIds` 为该 AIS 登录用户的 ID；普通账户的 Sandbox 交易仍拒绝。配置前必须确认审核信息里的 AIS 登录账户与该 ID 一致，完成后以 Sandbox 实际购买、服务端入账和积分刷新为验收证据。Xcode 本地 `.storekit` 交易不由 Apple 签名，不能代替这项验收。

## 3. 自动测试

### Core 与网络

- `MessageModel<T>`、分页和大整数 ID。
- JWT 注入、单飞 refresh、401/403、断网、超时、取消和安全重试。
- 区域配置、能力缓存和版本门禁。
- 文件上传、下载、缓存隔离和退出清理。

### 登录与账号

- 邮箱注册、验证码过期、密码登录和刷新。
- Apple 首次授权、隐藏邮箱、重复登录、nonce 错误、token 过期和账号冲突。
- 删除账号准备、二次验证、处理中、完成和旧 token 失效。

### Agent、模板与任务

- 模板筛选、动态字段、素材数量和报价。
- 模板页“用户案例”在 App 内浏览器打开 `/public-showcase`，关闭后正确返回模板页。
- 宣传标识全局偏好在重启后保留，新任务继承默认值，恢复旧草稿不反向覆盖全局设置。
- Agent 有限追问、记忆确认、Skill 推荐和越界输入。
- quote token 过期、重复确认、余额不足和并发确认。
- 任务成功、失败退款、部分失败、后台完成、通知深链和断线恢复。

### 账号、邀请与分享

- 覆盖 `VIP`、`Plus`、`Pro`、`Student`、`Max`、`Enterprise`、普通及未知会员等级的图标映射。
- 邀请页覆盖登录失效、邀请码与链接复制、二维码加载失败、空推荐名单、分页失败和重试。
- 微信分享仅发送合成后的完整海报图片，确认不会拆分成独立链接和缩略图；二维码可扫描并打开对应 `/ref/{InviteCode}` 或 `/share/{id}`。
- `AISOpaqueImageTests` 验证分享海报从带预乘 Alpha 的位图转换为无 Alpha 通道格式，并保持原始尺寸和缩放比例。
- 真机分享时检查 Xcode 控制台不再出现 `writeImageAtIndex` 的 `AlphaPremulLast` 警告；辅助功能框架自身的 `AX Safe category class` 日志不作为 AIS 缺陷。

### StoreKit

- 商品交集、价格本地化、成功、取消、pending、未验证和下架。
- AIS/PixaRivo 分别使用自己的 `appCode`、Bundle ID、Product ID、能力缓存和套餐缓存，确认双 App 不串商品。
- 购买后杀进程、断网、重复 transaction、重复通知和跨设备。
- Web/iOS 并发首充、规则版本切换、退款和余额不足冲正。
- 新安装及从上一审核版本更新后，在 iPad Air 11-inch (M3) 打开 Buy Points；无商品、能力关闭和网络失败均显示可重试状态，不允许空白页面。
- App Store Connect「用户和访问 → 沙盒」创建未用于普通 Apple Account 的测试邮箱；在设备「设置 → 开发者」登录 Sandbox Apple Account，购买弹窗确认显示 Sandbox 环境，不使用日常 Apple 账号测试。

## 4. 手工设备矩阵

最低覆盖：

- 当前最小支持版本 iOS 17 的 iPhone；
- 当前主流 iOS 版本的普通尺寸与 Max 尺寸 iPhone；
- iPad 紧凑与常规宽度；
- 简体中文和英文；
- 深色/浅色、Dynamic Type 最大可访问字号、VoiceOver、Reduce Motion；
- 弱网、断网、后台、系统回收和低存储空间；
- 相机/相册/通知允许与拒绝；
- 美国及至少一个非美元 storefront 的价格显示。

中国版额外覆盖中国网络、境内域名、对象存储、模型白名单和中文协议。

## 7. 灰度与回滚

- 首发选择少量已准备地区，观察登录、购买、生成成功率、退款和客服问题后扩大。
- 通过后端 capabilities 关闭视频、特定模型、公开内容或 StoreKit 档位。
- 不能通过远程配置绕过 Apple 审核新增完全不同的功能。
- 严重问题优先服务端停止创建新任务/新购，并保留用户查询、退款和账号删除。
- App 版本最低要求和强制更新由服务端控制，但必须保留审核与紧急使用路径。

## 9. 中国大陆前置事项

### APP 与 ICP

- 使用佳融公司现有 ICP 主体信息，但 iOS App 需要单独完成 APP 备案。
- 备案前固定中文 App 名称、Bundle ID、服务域名、服务类别、负责人和接入商。
- 由佳融公司与接入商/主管部门确认收费生成服务是否仅需备案，还是涉及 ICP 增值电信业务经营许可。

Apple 在 App Store Connect 的中国大陆可用性中可能要求填写 ICP 备案信息。参考：[App information](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information)。

### 生成式 AI

- 中国区只调用已完成备案或登记条件允许的模型服务。
- 由佳融公司办理生成式 AI 应用或功能登记，并在 App 显著位置公示模型和登记信息。
- 输入和输出都经过中国区内容安全，不能调用海外未批准模型作为静默回退。
- 生成内容继续执行显式标识、隐式元数据、内容编号、哈希追溯和合规日志。
