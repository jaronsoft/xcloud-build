# iOS 自适应图片交付与诊断查看器实施

> 状态：✅ 代码完成、专项测试通过并已上传 TestFlight，待真机回归
>
> 完成日期：`2026-07-26`

## 1. 实施目标

本轮根据图片实际显示宽度和屏幕倍率选择 capabilities 下发的最小可用缩略图档位，拆分网络请求与图片缓存查看器，并重新整理“我的”页面信息层级。发行方、全球运营方和中国区运营与技术支持信息继续保留。

## 2. 已完成内容

### 2.1 自适应图片交付

- iOS 默认图片能力增加 200px、400px、600px、900px 和 1200px 可配置档位。
- `.list`、`.largeList` 和 `.thumbnail` 根据“实际显示宽度 × displayScale”选择不小于目标的最小可用档位。
- 列表请求最大限制为 900px；能力缺少新增档位时自动回退现有 preset。
- `.detail` 继续使用约 1200px 规则，全屏预览、相册保存和文件导出统一使用 `.original`。
- 原图交付会移除 URL 中已有的 `imageMogr2`、`imageView2` 图片处理片段，同时保留版本号、签名等其他查询参数。
- CDN 域名和转换规则仍由 `/api/ais/capabilities` 下发，客户端不硬编码腾讯云查询参数。
- 不同尺寸和原图继续按最终 URL 建立独立缓存，相同最终 URL 保持内存、磁盘和并发请求合并。
- 列表图片在尚未取得布局宽度时先按 capabilities 的语义档位立即加载，取得宽度后再按需升级，避免瀑布流清缓存后停留在占位图。
- 服务端展示地址优先读取 `StorageInfo.CdnUrl`，`FileUrl` 中的 `www.get-free.net` 源图地址仅作兜底；公开案例缓存键升级至 `v5`。

### 2.2 图片缓存诊断

- 图片缓存事件改为结构化记录，包含模块、请求 preset、实际 preset、像素宽度、资源类型、来源、字节数、耗时和缓存键摘要。
- 图片缓存查看器醒目标注“400px 缩略图”“1200px 详情图”或“原图”。
- 像素宽度来自最终 CDN 规则或 capabilities 选择结果，不再只根据 `preset=list` 推测。
- 查看器支持按缓存模块和缩略图、详情图、原图类型筛选。
- URL 只记录域名、路径和不可逆缓存键摘要，不记录查询参数、Token、用户 ID 或图片内容。

### 2.3 独立诊断查看器

- “开发诊断”改为入口页，分别进入“网络请求”和“图片缓存”查看器。
- 入口页展示两类事件数量、图片缓存物理占用和统计时间。
- 统一保留“分享脱敏日志”和“清空日志”，界面不再显示 `.log` 扩展名。
- 导出文件命名为 `ais_diagnostics_时间戳.log`，使用 UTF-8、ISO 8601 时间和逐行文本格式，可由 macOS Console 打开。
- Debug 与 TestFlight 继续保留最近 7 天、最多 2 MB 的持久化脱敏日志。

### 2.4 “我的”页面

- iPhone 顺序调整为账户与会员、创作偏好、邀请与奖励、存储与诊断、帮助与运营主体、账户操作。
- iPad 左栏展示账户、会员和邀请；右栏展示偏好、存储、诊断、帮助和账户操作。
- 保留全球运营方（美国发行）和中国区主体信息。
- 中国区主体标题统一为“中国区运营与技术支持”，继续展示公司全称。
- 删除账号和退出登录仍位于独立危险操作区域。

## 5. 兼容与发布约定

- 未修改数据库；公开案例响应只调整已有图片地址的 CDN/源站优先级并升级响应缓存版本。
- capabilities 的 iOS preset 字典保持向后兼容，动态配置仍可覆盖默认档位。
- 历史图片缓存继续读取，无法识别归属的文件仍归入“其他缓存”。
- 当前已落地链路仍使用腾讯云 `cdn.jaronsoft.com` 及 `imageMogr2`/`imageView2` 规则。
- 中国以外区域已兼容 Cloudflare R2、Images Transformations 和独立域名 `cdn.get-free.net`；国际配置默认关闭，iOS 通过区域 capabilities 获取活动供应商和受控 `preset`，不在客户端自行判断供应商。
- 海外源图优先使用 Cloudflare R2 副本，`www.get-free.net` 仅作为记录地址或兼容兜底；全屏预览、保存和导出继续使用原图。
- 双区域后续方案见 [AIS 双区域图片交付与 Cloudflare 转换](../../../../documents/AIS/开发计划/0726%20AIS双区域图片交付与Cloudflare转换.md)。
