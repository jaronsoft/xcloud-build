# AIS iOS 腾讯云图片缩略图接入实施

更新时间：`2026-07-25`

## 1. 实施范围

原生端遵循仓库内 [AIS 腾讯云图片缩略图接入指南](../../../../documents/AIS/AIS-腾讯云图片缩略图接入指南.md)。启动页期间从 `/api/ais/capabilities` 下载图片交付配置，只在展示阶段处理服务端白名单中的 HTTPS 图片。API 模型、数据库、分享链接、下载入口和视频 URL 继续保留原始地址。

## 2. 代码落点

- `AIS/Core/Caching/AISImageURLBuilder.swift`：定义场景键、配置下载、磁盘缓存、线程安全快照和 URL 生成器；不包含域名及规则常量。
- `AIS/Core/Caching/AISImageCache.swift`：`AISCachedAsyncImage` 接收场景 preset，以处理后的 URL 作为缓存键。
- `AISTests/AISImageURLBuilderTests.swift`：验证参数分隔符、域名限制和重复处理保护。

配置下载与回退顺序：

1. 启动时优先读取 `AISResponseCache` 中最近一次成功配置；
2. 有缓存时立即进入应用并在后台刷新；
3. 首次安装没有缓存时最多等待接口 3 秒；
4. 接口失败时保留缓存，没有缓存则保持原始 URL。

生成器只有在 URL 同时满足以下条件时才追加规则：

1. scheme 为 `https`；
2. host 位于服务端下发的 `domains` 白名单；
3. URL 尚未包含 `imageMogr2/` 或 `imageView2/`。

## 3. 场景映射

| 场景 | preset | 腾讯云规则 |
| --- | --- | --- |
| 模板卡片、案例卡片 | `list` | 当前配置：`imageMogr2/thumbnail/600x` |
| iPad 大卡片预留 | `largeList` | 当前配置：`imageMogr2/thumbnail/900x` |
| 任务缩略图、参考素材、素材选择器 | `thumbnail` | 当前配置：`imageMogr2/thumbnail/200x` |
| 模板详情、案例详情、文字热点预览、分享卡片 | `detail` | 当前配置：`imageMogr2/thumbnail/1200x` |
| 固定正方形封面预留 | `square` | 当前配置：`imageView2/1/w/600/h/600` |

模板与案例默认等比缩放，不主动裁剪。只有明确要求正方形封面时才使用 `square`。
列表型图片会在取得实际渲染宽度后选择最小可用规格，其中 `thumbnail`、`list`
和 `largeList` 分别限制在 400、600 和 900 像素以内，避免首帧按默认大图发起请求后再次下载。

## 4. 缓存与失败边界

- 处理后的 URL 进入 `AISImageCache`，因此同一原图的不同规格分别建立缓存，避免详情错误复用低清缩略图。
- 相同规格的并发请求继续合并，磁盘缓存仍保留 7 天、上限 512 MB。
- 非服务端白名单图片不追加参数，继续沿用现有加载与占位逻辑。
- 腾讯云处理失败时由现有图片占位状态承接；如后续增加原图回退，只允许回退一次，避免循环重试。

## 5. 验收

- 模板与案例列表请求包含 `imageMogr2/thumbnail/600x`。
- 任务和素材小图请求包含 `imageMogr2/thumbnail/200x`。
- 详情与分享卡片请求包含 `imageMogr2/thumbnail/1200x`。
- 快速滚动列表时不再下载数 MB 原图，图片不串位，缓存体积符合上限。
- 非服务端白名单图片、视频和原图链路不出现图片处理参数。
- API 构建应保持 0 警告、0 错误，`AISImageURLBuilderTests` 应全部通过。

本次验证结果：API 构建 0 警告、0 错误；`AISImageURLBuilderTests` 定向测试 4/4 通过。

尚待真机验收：通过网络面板核对各场景实际请求宽度，验证长列表快速滚动不下载原图、不发生图片串位或异常内存增长，并抽查磁盘缓存回收后的体积。
