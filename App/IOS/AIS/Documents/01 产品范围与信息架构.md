# 产品范围与信息架构

## 1. 产品定义

AIS 是面向个人、品牌和企业的 AI 视觉创作平台。早期“产品智造”仍是重要的工业与外贸垂直场景，但不再限定产品名称、用户群和信息架构。

原生端由四类能力组成：

| 能力 | 用户价值 | 首版呈现 |
| --- | --- | --- |
| 快速创作 | 直接完成图片生成、图片编辑和可用时的视频生成 | 独立创作入口、规格选择、报价、任务和成果 |
| 风格模板 | 用真实案例和结构化表单降低提示词门槛 | 首页与模板 Tab 的核心入口 |
| 项目 Agent | 在项目上下文中澄清需求、推荐 Skill、报价并执行 | 受控项目对话，不是通用聊天 |
| Skill | 复用专业创作流程并形成稳定成果包 | 官方及审核通过的 Skill 列表和详情 |

## 2. 首版目标用户

- 工业制造与外贸团队：产品展示、场景图、上市素材和销售资料。
- 电商与品牌团队：商品图、活动图、社交媒体内容和风格统一。
- 内容创作者：通过模板和 Skill 快速制作视觉内容，但首版没有现金收益和提现。
- 普通用户：在清晰边界内完成个人视觉创作。

首版不以高风险专业建议、开放社区或用户间通讯为目标。

## 3. 主导航建议

采用五个一级入口：

1. **首页**
   - 推荐模板、快捷创作、精选 Skill、近期项目和后台审核案例。
2. **模板**
   - 分类、搜索、筛选、模板详情、真实作品、动态字段和一键创作。
3. **创作**
   - 快速图片生成、图片编辑、区域允许时的视频生成；也可进入受控 Agent。
4. **项目**
   - 项目列表、对话、引用素材、记忆建议、运行记录和成果看板。
5. **我的**
   - 余额、积分购买、交易记录、素材、语言、协议、隐私、客服、投诉和账号删除。

小屏 iPhone 使用 Tab Bar；iPad 可使用 `NavigationSplitView`，但路由语义保持一致。

## 4. 关键用户路径

### 4.1 模板创作

`浏览模板 → 查看真实作品与所需素材 → 填写字段/上传素材 → 请求报价 → 确认积分 → 启动任务 → 查看成果 → 保存/分享/继续修改`

模板详情必须在付费前展示：

- 成果类型和预计数量；
- 必填素材和用途；
- 预计积分与可能的赠送/会员影响；
- 预计耗时；
- 失败自动退款说明；
- AI 生成和内容标识说明。

### 4.2 项目 Agent

`创建项目 → 添加最多 3 张核心产品图 → 描述目标 → Agent 有限追问 → 推荐 Skill/模板 → 生成成果计划和报价 → 用户确认 → 幂等启动 → 成果看板 → 单成果继续修改`

Agent 的自由文本只是输入方式，执行必须转换为后端认可的结构化 Skill 参数。客户端不得从文本直接拼接任意工具调用。

### 4.3 快速创作

`选择图片生成/图片编辑 → 输入目标与规格 → 上传可选素材 → 请求报价 → 确认 → 任务 → 成果`

高级模型、视频和高分辨率能力都由后端 capabilities 决定；不可用时隐藏或解释，不在客户端硬编码会员门槛。

### 4.4 积分购买

`余额不足/我的余额 → 拉取后台 iOS 档位 → StoreKit 获取有效商品 → 显示本地价格与积分 → 用户确认购买 → StoreKit 交易 → 服务端验单和入账 → 刷新余额`

购买页不出现 Apple Pay、网页充值或其他支付方式。

## 5. 登录与访客

- 未登录用户可以浏览首页、模板、精选案例和公开 Skill。
- 上传素材、创建项目、发送项目消息、请求报价、启动任务、购买积分和保存成果必须登录。
- 首版支持邮箱登录与 Sign in with Apple。
- 若未来添加 Google、微信等第三方登录，必须重新核对 App Review Guidelines 4.8，并保持 Sign in with Apple 的等价入口。
- 支持账号创建就必须在“我的 → 设置 → 账号与安全”提供账号删除。

## 6. 聊天边界

### 允许

- 围绕当前项目收集品牌、产品、渠道、受众、风格、画幅和成果数量。
- 对缺少的结构化参数做有限追问。
- 推荐已发布的 Skill 和模板。
- 展示计划、报价、预计耗时和失败处理。
- 在用户确认后保存记忆或启动付费任务。

### 不允许

- 开放式通用问答和与视觉创作无关的无限话题。
- 医疗、法律、金融等高风险专业建议。
- 任意联网搜索、执行用户代码或访问用户提供的任意 URL。
- 未经确认扣费、连续生成或增加成果数量。
- 用户间私聊、匿名聊天、评论和关注。
- 暴露内部 Prompt、私有 Skill 规则、模型密钥或其他用户数据。

## 7. 公开内容与创作者

- 首页、Gallery 和 Skill 示例只显示后台审核通过的内容。
- 必须提供内容举报、屏蔽或下架处理链路；首版没有自由发布社区，仍应为精选内容提供投诉入口。
- 创作者可提交 Skill 供平台审核，但不展示收益余额、分成比例、收款资料和提现。
- 现有后端收益/提现能力保持 Feature Flag 关闭，iOS 不调用相关接口。

## 8. 首版明确不做

- 自动续费订阅不纳入首个支付闭环，下一阶段按 [iOS 自动续费订阅与区域定价策略](./21%20iOS自动续费订阅与区域定价策略.md) 独立实施。
- 创作者现金收益与提现。
- 自定义金额充值。
- Apple Pay、微信、支付宝、Stripe、PayPal 和网页充值。
- 通用聊天、用户社交、开放社区和未经审核的公开发布。
- 可执行代码、自定义 HTTP 请求和浏览器自动化 Skill。
- Widget、Share Extension、App Clip、macOS 和 visionOS。

## 9. 名称与视觉身份

- 开发工作名使用 `AIS`，工程和代码内部保持 `AIS` / `ais` 术语。
- Bundle ID 使用长期稳定的 `com.wekarepartners.studio`。
- 正式产品名应表达“视觉创作 + 模板 + Agent + Skill”，不建议继续只用“产品智造”解释全部能力。
- 正式名称确认前，不创建不可逆的商店名称依赖；名称确认后同步 App Display Name、商店副标题、域名、协议、客服和中国区备案材料。

## 10. 产品验收原则

- 用户能在 App 内独立完成浏览、登录、上传、报价确认、生成、购买积分、查看任务、保存成果和删除账号。
- 核心路径不依赖 WebView。
- 所有价格和积分在付费前清晰展示，所有付费任务都需要用户明确确认。
- 功能根据区域和服务端能力收敛，不通过客户端隐藏配置绕过合规限制。
