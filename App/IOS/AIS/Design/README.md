# AIS Prismatic Intelligence

AIS iOS 视觉系统以“棱镜智能”为核心概念：创作素材进入棱镜，经过理解、重组与增强，输出可直接使用的视觉成果。

## 视觉语言

- 背景：深墨蓝 `#060913`
- 主色：电子紫 `#8C5CFF`
- 辅色：智能青绿 `#29E0C7`
- 强调色：暖珊瑚 `#FF7A66`
- 材质：深色空间、柔和玻璃、晶体折射与克制辉光
- 字体：沿用 iOS 系统字体，标题使用 Rounded Design

运行时图片统一维护在 `AIS/Resources/Assets.xcassets`，本目录不再重复保存素材副本。
图片不内嵌文字，双语文案由 SwiftUI 本地化层负责，避免图片文字造成语言和无障碍问题。
