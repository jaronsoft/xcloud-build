# 辅助功能与账户级合规

## 1. Accessibility Nutrition Labels

Apple 的辅助功能营养标签会显示在 iOS 26 或更新系统的产品页。当前 Apple 仍允许自愿填写，但只能在常见核心任务经过对应标准测试后声明支持。

PixaRivo 使用 SwiftUI 和语义字体是良好基础，但当前代码不足以直接证明完整支持。首次填写建议：

```text
Does your app support any listed accessibility features on iPhone?
No — until the complete iPhone evaluation is finished.

```

这不是表示 App 没有任何辅助功能，而是避免在未按 Apple 标准验证完整核心路径前作出不准确的产品页声明。完成测试后再发布真实标签，不需要等待新二进制版本。

### 分项评估表

| 标签 | 当前建议 | 发布“支持”前的最低验证 |
| --- | --- | --- |
| VoiceOver | 暂不声明 | 首页、搜索、模板卡片、模板详情、登录、照片选择、文字编辑、提交和作品列表可完整操作；所有功能图片有有意义标签 |
| Voice Control | 暂不声明 | 所有按钮、字段、Tab 和照片槽位可通过名称或编号操作，无重复/缺失名称 |
| Adjustable Text Size | 暂不声明 | 系统文字大小调整有效，固定高度控件不截断主要信息 |
| Larger Text | 暂不声明 | 在 Apple 要求的较大辅助文字尺寸下完成登录、选择模板、编辑和提交，不遮挡或丢失操作 |
| Dark Interface | `No` | `UIUserInterfaceStyle = Light` 强制浅色，当前不能声明深色界面 |
| Differentiate Without Color Alone | 暂不声明 | 选中、错误、状态和进度除颜色外同时有文字、形状或图标 |
| Sufficient Contrast | 暂不声明 | 用 Accessibility Inspector 检查浅色界面的文字、图标和控件；普通文字通常达到 4.5:1，非文字控件达到适用标准 |
| Reduced Motion | 暂不声明 | 开启 Reduce Motion 后启动品牌动效自动缩短为淡入淡出，并可完成全部核心任务，确认没有必要动画造成障碍 |
| Captions | 不适用/不声明 | 当前无包含语音的视频或音频内容 |
| Audio Descriptions | 不适用/不声明 | 当前无需要音频描述的视频内容 |

当前仅需在受支持的 iPhone 设备族上评估。模板和案例属于核心视觉内容；如果 VoiceOver 用户无法理解图片目的，就不能仅因系统控件可读而声明完整支持 VoiceOver。

官方评估入口：[Overview of Accessibility Nutrition Labels](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/overview-of-accessibility-nutrition-labels/)。

## 2. 欧盟 Digital Services Act（DSA）

无论是否在欧盟销售，App Store Connect 都会要求声明 trader 状态。PixaRivo 由商业公司 `WeKare Partners LLC` 提供并用于商业服务，建议由 Account Holder 在法务确认后选择：

```text
Trader
```

如果在欧盟 27 个地区分发，Apple 会在产品页公示并验证：

| 字段 | 待填写 |
| --- | --- |
| Legal Entity | `WeKare Partners LLC` |
| Business Address | `[DSA_ADDRESS]` |
| Phone Number | `[DSA_PHONE]` |
| Email Address | `[DSA_EMAIL]` |

这些信息必须来自公司正式记录并能完成 Apple 验证，不能用仓库中的中国合作方地址替代美国发行主体地址。若公司决定选择 non-trader，必须保留能够支持该判断的法律意见，不能仅为隐藏联系信息而选择。

## 3. 韩国 storefront

组织开发者如在韩国分发 App，App Store Connect 可能要求提供韩国电子商务法规联系信息。由 Account Holder 准备：

| 字段 | 待填写 |
| --- | --- |
| Trade Name / Company | `WeKare Partners LLC` 或经法律确认的当地名称 |
| Representative | `[KOREA_CONTACT_NAME]` |
| Address | `[KOREA_CONTACT_ADDRESS]` |
| Phone | `[KOREA_CONTACT_PHONE]` |
| Email | `[KOREA_CONTACT_EMAIL]` |

PixaRivo 不是游戏，不需要韩国 GRAC 游戏分级编号。若无法完成韩国联系信息要求，首发不要选择韩国 storefront。

## 4. 中国大陆 storefront

中国大陆可用性字段按实际备案状态填写。当前资料包建议首发关闭中国大陆，直到至少完成：

- App 备案及与 Bundle ID、中文名称、域名和运营主体一致的材料；
- 生成式 AI 应用/功能登记与模型信息公示；
- 生成合成内容标识、内容安全、投诉举报和日志留存验收；
- 中国区数据存储、跨境处理、客服、协议和隐私政策审查；
- 如涉及收费服务，对 ICP/增值电信许可要求完成法律确认。

完成后再在 App Store Connect 填写 Apple 要求的备案号或中国大陆可用性信息，不要使用 AIS 主 App 或其他主体的编号代填。

## 5. 越南及其他地区合规

App Store Connect 若因所选 storefront 显示越南或其他国家/地区的额外合规字段，Account Holder 应按 PixaRivo 的真实业务、主体和当地法律填写。无法确认时先取消该 storefront，不推测许可证、代表人或备案编号。

## 6. Account Holder 级资料清单

以下不是 PixaRivo 文案，但会影响能否提交或销售：

- Apple Developer Program 会员有效，法定实体名称为 `WeKare Partners LLC`；
- 公司地址、D-U-N-S、Account Holder 和团队权限准确；
- 最新 Apple 协议已接受；
- 即使 App 免费，也已完成 Apple 要求的合规审查；
- PixaRivo 已启用 IAP，Paid Apps Agreement、W-9、银行账户和税务资料必须在销售前完成并保持有效；
- DSA trader 状态及公开联系方式已验证；
- App Manager/Developer 有权创建 App、上传构建和提交审核；
- App Review 联系人不同于公开 DSA 联系人时，两套信息分别保持有效。
