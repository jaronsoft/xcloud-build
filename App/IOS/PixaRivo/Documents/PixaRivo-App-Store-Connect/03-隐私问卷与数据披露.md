# 隐私问卷与数据披露

## 1. App Privacy 总体回答

问题“您或第三方合作伙伴是否从此 App 收集数据？”选择：

```text
是，我们会从此 App 收集数据。
Yes, we collect data from this app.
```

这里的“收集”包括数据离开设备并由运营方或服务商保留。PixaRivo 会将邮箱登录信息、用户选择的图片、模板文字和任务信息发送到服务端，因此不能选择“不收集数据”。

所有已确认数据类型均选择：

- 用于跟踪：`否 / No`；
- 与用户身份关联：除非服务端经核查证明已在收集前不可逆匿名化，否则选择 `是 / Yes`；
- 主要用途：`App 功能 / App Functionality`。

## 2. 建议勾选的数据类型

| App Store Connect 数据类型 | 是否收集 | 与身份关联 | 用途 | 代码/业务依据 |
| --- | --- | --- | --- | --- |
| Contact Info → Name | 是 | 是 | App Functionality | 注册时填写昵称并与账号关联 |
| Contact Info → Email Address | 是 | 是 | App Functionality | 邮箱密码登录，服务端返回并保存账号邮箱 |
| Contact Info → Phone Number | 是（可选提供） | 是 | App Functionality | 注册页允许用户选填手机号；只要服务端接收可选值，即应按收集披露 |
| Identifiers → User ID | 是 | 是 | App Functionality | 用户 ID 与登录会话、任务和作品关联 |
| User Content → Photos or Videos | 是 | 是 | App Functionality | 用户主动选择图片并上传用于模板合成 |
| User Content → Other User Content | 是 | 是 | App Functionality | 用户填写模板允许编辑的标题和文字 |
| Purchases → Purchase History | 建议是 | 是 | App Functionality | 每次合成会产生积分报价和任务点数记录；如确认积分记录不属于 Apple 定义的购买历史，可经法务复核后取消 |
| Usage Data → Product Interaction | 建议是 | 是 | App Functionality | 模板使用、合成任务、任务进度和作品历史保存在服务端 |
| Diagnostics → Other Diagnostic Data | 条件勾选 | 通常是 | App Functionality | 仅当服务端保留请求错误、安全或诊断日志时勾选；设备内日志不会自动上传 |

## 3. 当前不应勾选的数据类型

在最终网络审计没有发现新增采集前，以下选择为“不收集”：

- Physical Address、Other User Contact Info；
- Health、Fitness、Financial Info、Sensitive Info；
- Precise Location、Coarse Location；
- Contacts、Browsing History、Search History；
- Device ID、Advertising Data；
- Emails or Text Messages、Audio Data、Gameplay Content；
- Crash Data、Performance Data（当前工程未集成崩溃或分析 SDK）；
- Other Data Types。

说明：注册页会让用户选择国家/地区，默认值由 Locale 推导；App 也会发送系统语言、客户端平台和媒体区域，但不会读取 GPS。提交前应通过服务端字段和 Apple 当期定义确认注册国家/地区应归入 `Other Data Types`、联系信息或其他类别；若服务端通过 IP 保留位置并用于账号画像，还应重新评估 `Coarse Location`。邀请码同样应在最终数据审计中确认是否保存及其用途。

## 4. 逐项问卷答案

对“Name、Email Address、Phone Number、User ID、Photos or Videos、Other User Content、Purchase History、Product Interaction”分别填写：

| 问题 | 回答 |
| --- | --- |
| 此数据是否用于第三方广告？ | 否 |
| 此数据是否用于开发者广告或营销？ | 否 |
| 此数据是否用于分析？ | 否；只有真实用于统计分析时才改为是 |
| 此数据是否用于产品个性化？ | 否；当前模板并非依据个人画像推荐 |
| 此数据是否用于 App 功能？ | 是 |
| 此数据是否用于其他目的？ | 否 |
| 此数据是否与用户身份关联？ | 是 |
| 此数据是否用于跟踪？ | 否 |

如勾选 `Other Diagnostic Data`，用途选择 `App Functionality`；若仅用于稳定性和故障分析，也同时选择 `Analytics`，但必须与真实服务端处理一致。

## 5. 权限说明

| 权限/能力 | 当前实现 | 对用户的中英文说明 |
| --- | --- | --- |
| 照片选择 | 使用 `PhotosPicker`，用户主动选择模板图片时触发；系统照片选择器通常不授予 App 完整照片库权限 | 中文：选择要替换到模板中的图片。英文：Choose images to replace content in a template. |
| 保存到相册 | `Info.plist` 已有用途说明，但当前代码未实现保存动作 | 送审前若仍无保存功能，应删除该用途说明；如实现，必须只在用户点击保存时申请 |
| 相机 | 未使用 | 不申请 |
| 麦克风 | 未使用 | 不申请 |
| 定位 | 未使用 | 不申请 |
| 通知 | 登录后先解释用途，用户确认后申请；用于积分、会员、充值退款和作品状态提醒 | 中文：接收积分、会员权益和作品状态通知。英文：Receive updates about points, membership benefits, and creation status. |

现有 `NSPhotoLibraryUsageDescription` 与 `NSPhotoLibraryAddUsageDescription` 只有中文且未本地化。若工程始终只使用 `PhotosPicker` 且不直接读取照片库，可移除前者；当前又没有保存相册实现，应移除后者。若未来真实调用相应权限 API，则必须保留用途说明并增加准确的英文 InfoPlist 本地化。

## 7. App 内隐私与账号删除入口

推荐路径：

```text
我的 → 关于 → 隐私政策
Me → About → Privacy Policy
```

入口应直接打开对应语言的隐私政策，不应只依赖服务条款中的间接链接。

当前构建已经提供邮箱验证码注册，因此还必须在 App 内提供可发起完整账号删除的入口，例如：

```text
我的 → 账户与安全 → 删除账号
Me → Account & Security → Delete Account
```

入口可以包含身份复核和风险提示，但不能只要求用户访问网页或发送一般客服邮件。网页 `#rights` 和 `ais@get-free.net` 作为补充隐私渠道继续保留。

图片或文字首次发送到云端/AI 服务前，建议展示简短说明：

```text
为完成模板合成，你选择的图片和填写的文字将上传到 PixaRivo 的云端服务，并可能由受约束的 AI 与存储服务商处理。请勿上传无权使用或包含不必要敏感信息的内容。继续即表示你已阅读隐私政策并同意本次处理。
```

```text
To compose this template, your selected images and entered text will be uploaded to PixaRivo’s cloud service and may be processed by contracted AI and storage providers. Do not upload content you do not have the right to use or unnecessary sensitive information. By continuing, you acknowledge the Privacy Policy and consent to this processing.
```

## 8. PrivacyInfo.xcprivacy 核对

当前清单声明不跟踪、无 tracking domains、无 collected data types、无 required-reason API。该文件不能替代 App Store Connect 的隐私问卷。

归档前必须用 Xcode Privacy Report 核对：

- App 和所有系统/第三方依赖合并后的隐私清单；
- `UserDefaults` 等 required-reason API 是否需要声明；
- App Store Connect 问卷、隐私政策和真实网络请求是否一致；
- 未引入分析、崩溃、广告或设备指纹 SDK。
