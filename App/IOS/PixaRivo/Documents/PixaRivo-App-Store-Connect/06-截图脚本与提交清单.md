# 截图脚本与提交清单

<!-- markdownlint-disable MD013 -->

## 1. 截图规格

PixaRivo 当前仅支持 iPhone，因此只准备 iPhone 截图。每种本地化可上传 1–10 张截图；首发建议中文和英文各 6 张。App Preview 视频可不提供。

建议使用当前最高规格竖屏截图：

| 设备 | 可接受的推荐尺寸 |
| --- | --- |
| iPhone 6.9 英寸 | `1320 × 2868`、`1290 × 2796` 或 `1260 × 2736` px |

截图格式使用 `.png`、`.jpg` 或 `.jpeg`，不能包含 alpha/透明通道。最终仍以 Apple [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) 页面当日列出的尺寸为准。

## 4. 截图制作规则

- 中文商店使用中文界面，英语（美国）商店使用英文界面，不在同一张图混排两种语言。
- 截图必须来自当前仅支持 iPhone 的真实发行构建，不制作或上传 iPad 设备族截图。
- 使用当前准备送审的真实构建；可以展示已经完成的原图保存、分享、IAP 和订阅，但不得展示尚未实现的点赞、评论、自由生图、视频或项目 Agent。
- 状态栏时间、网络和电量保持一致；不要显示调试浮层、模拟器边框、鼠标、布局辅助线或占位数据。
- 仅使用取得 App Store 营销展示权的模板和案例。
- 不显示审核账号邮箱、密码、真实人物敏感信息、客户商标、Token、内部任务 ID 或诊断日志。
- 图片和文案保留足够安全边距，避免被圆角、灵动岛或商店裁切遮挡。
- 若加入设备框，必须使用 Apple 允许的设备素材和当前设计规范；纯截图同样可接受。
- 导出后检查没有透明通道，文件名按语言、设备和顺序统一。

建议文件名：

```text
zh-Hans-iphone-01-home.png
en-US-iphone-01-home.png
```

## 5. Product Page Optimization 与 App Preview

首发先不启用 Product Page Optimization、Custom Product Pages 或 App Preview，减少审核变量。收集真实下载和转化数据后，再测试“模板效率”“社交内容”“品牌视觉”等不同卖点。

## 6. 提交前清单

### App Store Connect

- [ ] App 名称通过可用性检查，Bundle ID 和 SKU 正确。
- [ ] 简体中文和英语（美国）的名称、副标题、推广文本、描述、关键词均已保存。
- [x] 两种语言的隐私政策、服务条款和技术支持 URL 已于 2026-08-12 在未登录浏览器完成访问检查。
- [ ] 将已验证 URL 保存到 App Store Connect 对应本地化字段，并从审核目标地区再次复查。
- [ ] 版权填写为 `© 2026 WeKare Partners LLC`。
- [ ] 主要类别为 Graphics & Design，次要类别为 Photo & Video。
- [ ] App 价格为 Free；消耗型积分商品、首个自动续费订阅组及其中的 Plus/Pro 月度商品均已加入本次审核。
- [ ] 每个 IAP/订阅已填写本地化名称、描述、价格、可售地区、审核截图和审核备注，状态可随 App 版本提交。
- [ ] 税务类别保持 App Store software，License Agreement 使用 Apple Standard EULA。
- [ ] 销售地区已排除尚未完成合规准备的地区。
- [ ] DSA trader 状态已声明；如在欧盟销售，公示联系信息已由 Apple 验证。
- [ ] 如在韩国销售，组织开发者的韩国联系信息已填写；不销售则确认未选择韩国 storefront。
- [ ] App Privacy 已按最终服务端数据流发布。
- [ ] App Accessibility 已按真实 iPhone 测试结果填写，未验证的能力没有宣称支持。
- [ ] 更新后的年龄分级问卷已完成并记录实际评级。
- [ ] 内容版权问题选择 Yes，所有模板、案例、字体和截图授权已留档。
- [ ] 出口合规回答与 `ITSAppUsesNonExemptEncryption = false` 一致。
- [ ] iPhone 中文、英文两组截图均已上传。
- [ ] 已选择正确的待审构建；当前营销版本为 `1.2.12`。确认自动流程生成了高于 App Store Connect 现有最高值且未被占用的 Build，并在 App Store Connect 处理完成后同步全部资料。
- [ ] 审核联系人、专用账号、密码和 Review Notes 已填写，所有占位符已替换。
- [ ] 发布方式选择手动发布。

### App 与后端

- [ ] App 内有可直接访问的 PixaRivo 隐私政策、服务条款和技术支持入口，不再指向 AIS 页面。
- [ ] App 内提供可发起完整账号删除的入口，并完成身份复核、取消和提交路径测试。
- [ ] 英文系统中的安装名称和品牌标题与英文商店名称一致，不残留未说明的固定中文 `图漾`。
- [x] 支持页已明确显示 PixaRivo、`ais@get-free.net`、数据/删除请求和投诉方式。
- [ ] 审核账号无需验证码或人工协助，且有足够测试积分。
- [ ] 模板、图片 CDN、登录、报价、上传、合成和任务接口在审核地区可用。
- [ ] 用户首次上传图片/文字前可看到云端和第三方处理说明。
- [ ] 公开案例经过授权、内容审核并具备举报/下架流程。
- [ ] App 内不存在外部数字积分购买引导。
- [ ] 仅使用系统 `PhotosPicker` 时核对是否可删除多余的 `NSPhotoLibraryUsageDescription`；如保留直接照片库访问，补齐中英文用途说明。
- [ ] 删除未实现保存相册功能时多余的 `NSPhotoLibraryAddUsageDescription`，或实现对应功能并按需申请。
- [ ] Release 构建不显示 TestFlight 专用网络诊断入口。

### 构建与真机

- [ ] 使用 Apple 当前要求的正式版 Xcode 和 SDK 归档。
- [ ] Release Archive 成功，Bundle ID、版本、构建号、最低系统和设备族正确。
- [ ] Xcode Privacy Report 无未知 SDK、无效清单或未声明 required-reason API。
- [ ] iPhone 真机完成中英文登录、模板、选图、编辑、合成和作品回归。
- [ ] 开启和关闭系统“减少动态效果”分别验证启动过渡；动效不能阻塞首页交互或后台数据加载。
- [ ] 验证弱网、Token 失效、积分不足、上传失败和合成失败提示。
- [ ] 验证 Dynamic Type、VoiceOver、深色模式策略和横竖屏行为符合当前产品设计。
- [ ] TestFlight 安装验证生产 API，不使用仅模拟器可用的路径。
- [ ] App Store Connect 处理构建后没有隐私、加密、缺失合规或符号警告。

## 7. 提交后

- 保持审核账号、服务端、模板、图片和合成队列持续可用。
- 每天查看 App Review 消息并使用英文准确回复。
- 如 Apple 询问积分，明确消耗型积分和自动续费订阅只通过 Apple IAP 提供，审核账号预置积分仅用于免购买审核合成流程；不得提供网页购买链接。
- 如 Apple 询问案例内容，提供筛选、授权、举报和下架流程说明。
- 如 Metadata Rejected，只修正元数据即可；如 Binary Rejected，修复代码并递增构建号后重新上传。
- 审核通过后按既定时点手动发布，并监控登录、上传、合成成功率、客服和隐私请求。
