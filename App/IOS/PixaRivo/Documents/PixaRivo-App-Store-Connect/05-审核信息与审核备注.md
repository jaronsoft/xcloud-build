# 审核信息与审核备注

## 1. 联系信息

在 App Store Connect → App 审核信息中填写：

| 字段 | 填写值 |
| --- | --- |
| First Name | `[REVIEW_FIRST_NAME]` |
| Last Name | `[REVIEW_LAST_NAME]` |
| Phone Number | `[REVIEW_PHONE]`，使用含国家区号且审核期间可接听的号码 |
| Email | `[REVIEW_EMAIL]`，使用审核期间持续收件的工作邮箱 |
| Sign-in required | `Yes` |
| Username | `[DEMO_EMAIL]` |
| Password | `[DEMO_PASSWORD]` |

虽然模板和案例无需登录即可浏览，但核心合成和个人作品功能需要登录，因此必须提供演示账号。

## 2. 审核账号要求

- 专供 Apple 审核，长期有效，不使用员工或真实客户账号；
- 不启用一次性验证码、IP 白名单、设备绑定或审核员无法完成的二次验证；
- 预置足够完成至少 10 次模板合成的积分；
- 使用非敏感演示作品，避免真实邮箱以外的个人信息和客户素材；
- 后端、图片存储、模板列表和合成队列在审核期间持续可用；
- 如密码变更，提交前同步更新 App Store Connect；
- 不把账号密码写入本仓库。

## 6. 审核附件

通常不需要附件。如果合成时间长、后端区域限制或模板步骤难以复现，可附一个不超过几分钟的英文演示视频，依次展示登录、选择图片、编辑文字、提交合成和在“作品”查看结果。附件不得显示真实凭证、Token、客户素材或内部管理页面。
