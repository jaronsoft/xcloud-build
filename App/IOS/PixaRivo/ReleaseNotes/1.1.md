# PixaRivo 1.1 时间线

<!-- markdownlint-disable MD013 MD024 -->

本文件按版本顺序保存现有的 1.1.x 记录；未出现的版本暂无发布说明，不补写日期、Build 或更新内容。

## 1.1.8 — 2026-08-17 (Build 29) — 已发布

### 简体中文

- 支持高清原图保存到相册啦，模板、精选案例和自己的作品都能随时下载！
- 作品列表支持一直往下滑加载更多，过往的所有创作都能轻松翻到。
- 生成中的任务直接显示模板名称和当前进度状态，告别看不懂的数字编号。
- 生成前和生成中都能看到预计耗时，大概还要等多久心里更有底。
- 创建按钮直接显示实付积分与优惠折扣，未填写或未修改内容时会主动提醒，防止误创建任务。
- 积分不足时会在创作前显示差额，并可前往购买积分或开通包月；返回后已填写的创作内容仍会保留。
- 积分变动、会员权益、充值退款和作品生成进度，消息提醒更及时。
- 还顺手修复了部分图片被裁切显示不全、新用户注册积分偶尔没到账等小问题，用起来更顺手。

### English (U.S.)

- You can now save high-res original images directly to Photos from templates, showcases, and your own works!
- Keep scrolling! The Works tab now supports infinite scrolling so you can easily browse your full creation history.
- Clearer task titles: Ongoing tasks now show the template name and current progress instead of a confusing task ID.
- Real-time time estimates: Check how long generation will take before and during creation.
- Streamlined creation: See point costs and discounts upfront, with a warning before creating from an unchanged form.
- Low-balance guidance: See how many more points you need, then buy points or choose a monthly plan without losing your edits.
- Smarter notifications: Get timely updates on point balance changes, membership perks, payments, refunds, and creation progress.
- Bug fixes & polish: Fixed cropped thumbnail previews, resolved occasional sign-up bonus point delivery issues, and made the app feel smoother overall.

## 1.1.11 — 2026-08-20 (Build 待确认) — 已发布

### English (U.S.)

- Improved the notification center with clearer titles and message previews, plus a dedicated view for full details.
- Added swipe-to-delete with a confirmation that clearly warns deleted messages cannot be recovered.
- When viewing a deeper page in any tab, tap the current bottom tab again to go back one level at a time.
- Improved network reliability by automatically recovering from occasional compressed-response errors, reducing load failures on subscription status and other screens.
- Improved App Store catalog loading with an automatic retry for temporarily missing products and clearer server-versus-Apple error messages.

## 1.1.12 — 日期待确认 (Build 待确认) — 已发布

### 简体中文

- 创作素材上传任务改为在作品页顶部逐条展示真实进度；进入服务端确认阶段后切换为等待状态，多任务提交时进度互不干扰。

- Fixed submitted tasks remaining as failed entries after duplicate-request recovery, as well as local tasks being counted twice in work totals and badges.
- Improved API connection reliability by selecting a more suitable regional endpoint and automatically switching when an endpoint is unavailable.

## 1.1.13 — 2026-08-23 (Build 待确认) — 已发布

### 简体中文

- 模板页新增完整筛选面板，可按排序、画幅方向、兼容渠道，以及行业、用途、设计风格、摄影风格、主题和主体等动态模板标签组合筛选，并在列表顶部显示当前条件。
- 分享模板、案例和作品时，分享图会显示 App Store 下载提示及二维码，方便接收者直接获取 PixaRivo。
- 优化 API 节点选择：启动时并发检测国内与海外服务节点的 TLS 连通性和响应速度，仅在备用节点明显更快时切换；Wi-Fi、蜂窝网络或 VPN 路径变化后会静默重新检测，减少部分网络环境下的 TLS 连接失败。
- 案例详情新增“创建同款”入口，可直接载入案例对应模板开始创作；未登录时完成登录后会自动继续。
- 修复订阅状态数据返回成功后仍可能加载失败的问题，提升积分购买和包月方案页面的稳定性。
- 全新启动动效以杂志海报风格呈现品牌理念，并通过三张动态视觉技能卡片展示“选择风格、添加图片、编辑文字”的创作流程；中英文界面均有专属排版。
- 模板分享到 X 时会自动附加当前语言的公开创作提示词，方便读者理解并复用创作思路；微信等其他渠道仍保持单张完整分享海报。

### English (U.S.)

- Added a complete template filter panel with sorting, orientation, compatible channels, and dynamic tags for industry, purpose, design style, photography, topic, and subject. Active filters remain visible above the template list.
- Shared template, gallery, and work images now include an App Store download prompt and QR code so recipients can get PixaRivo directly.
- Improved API endpoint selection by checking TLS reachability and response time across regional nodes at launch, switching only when another endpoint is materially faster, and silently rechecking after Wi-Fi, cellular, or VPN path changes.
- Added a “Create with This Template” action to case details, allowing users to open the source template and continue automatically after signing in when required.
- Fixed an issue where subscription status could fail to load despite a successful response, improving reliability across point purchases and monthly plans.
- Redesigned the launch experience with an animated editorial poster, three visual Skill cards, and a clear choose–add–edit creation flow, with dedicated layouts for Chinese and English.
- Template shares to X now include the localized public creation prompt for easier discovery and reuse, while other destinations such as WeChat continue to receive one complete poster image.

- Improved the initial creation-template loading experience so a loading state appears immediately instead of a briefly blank screen.
- Improved the Monthly Plans empty state and action layout, removing unused space when no alternate plans are available and making subscription management and purchase restoration clearer.
- Increased information density across gallery and template lists with smaller card titles, metadata, and spacing, while moving gallery share controls away from text so more content and fuller titles fit on screen.
